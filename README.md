# Price Monitor — PS5 Pro (Brasil)

Projeto de monitoramento de preços com:
- Playwright (scraping)
- SQLite (histórico)
- Streamlit (dashboard)

## Funcionalidades
- Coleta automática do preço por URL
- Histórico no SQLite
- Dashboard com imagem, preço atual, link do anúncio, tabela e gráfico

## Como rodar (Windows / CMD)

### 1) Clone o repositório

git clone <https://github.com/GustavoUrsino22/PS5-PRO-PRICE-MONITOR-BRASIL>
